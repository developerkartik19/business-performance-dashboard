# business-performance-dashboard
Interactive business performance and revenue analytics dashboard with lead, quotation, deal, order and payment tracking, date-range comparison, and filters. Built with JavaScript and dummy data.
A responsive business performance and revenue analytics dashboard that tracks leads, quotations, deals, orders, payments and team performance.

Live demo: https://developerkartik19.github.io/kartiks-dashboard/

Features
Eight KPI cards with change versus the previous equivalent period
Date filters: Today, Last 7 Days, Last 30 Days and a custom range
User and department filters that apply across every view
Global search across leads, quotations, deals and orders
Charts for lead funnel, lead trend, lead sources and revenue vs collection
Quotation analytics, order stages and team performance tables
CSV export of the current view
Dark theme, mobile-friendly layout
Tech

HTML, CSS and vanilla JavaScript with inline SVG charts. All data is generated dummy data, so no backend is needed.

Run locally

Rename northstar-dashboard.html to index.html and open it in a browser.

Note

This is a demo project built with dummy data.
